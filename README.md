**Описание**

Представим, что ты создаешь систему управления заказами в интернет-магазине. В этой системе нужно использовать **enum**
для представления различных статусов заказа и типов оплаты.

**Подробности**

1. Создать enum OrderStatus, который будет представлять возможные статусы заказа:

        * Pending — заказ ожидает подтверждения.
        * Processing – заказ в обработке.
        * Shipped — заказ отправлен.
        * Delivered — заказ доставлен.
        * Canceled — заказ отменен.


2. Создать enum PaymentType, который будет представлять типы оплаты:

        * CreditCard— оплата кредитной картой.
        * PayPal- оплата через PayPal.
        * BankTransfer— оплата через банковский перевод.
        * CashOnDelivery- оплата при доставке.

3. Создать интерфейс Order, содержащий поля:

        * id- уникальный идентификатор заказа (типа string).
        * amount- общая сумма заказа (типа number).
        * status- статус заказа (типа OrderStatus).
        * paymentType- тип оплаты (типа PaymentType).

4. Создать несколько заказов для тестирования системы, используя OrderStatusи PaymentType.

5. Написать функцию updateOrderStatus, которая принимает order: Orderи status: OrderStatusобновляет статус заказа, а
   также выводит в консоль сообщение об изменении статуса.
6. Написать функцию getOrdersByStatus, которая принимает массив orders: Order[]и status: OrderStatus, и возвращает все
   заказы с соответствующим статусом.
